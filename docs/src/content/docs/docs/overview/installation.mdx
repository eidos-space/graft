Install only the surface your application uses.

<Tabs>
  <TabItem label="CLI">

  ```bash
  curl -fsSL https://graft.eidos.space/install.sh | sh
  graft --version
  ```

  The installer downloads the latest published binary for the current platform.
  To pin a release:

  ```bash
  curl -fsSL https://graft.eidos.space/install.sh \
    | GRAFT_VERSION=0.15.5 sh
  ```

  Prebuilt archives are also available from
  [GitHub Releases](https://github.com/eidos-space/graft/releases).

  Once installed, update the current CLI in place with:

  ```bash
  graft upgrade
  ```

  </TabItem>
  <TabItem label="Node.js SDK">

  ```bash
  pnpm add @eidos.space/graft
  ```

  The package supports Node.js 20 and newer and selects a prebuilt Node-API 8
  binary for the current platform. Continue with the
  [SDK quickstart](/docs/sdk/quickstart/).

  </TabItem>
  <TabItem label="Remote service">

  Choose the package that matches the host:

  ```bash
  pnpm add @eidos.space/graft-remote
  pnpm add @eidos.space/graft-remote-hono hono
  pnpm add @eidos.space/graft-remote-cloudflare
  ```

  Read [Remote Service](/docs/remotes/) before choosing a protocol engine,
  routing adapter, or Cloudflare storage adapter.

  </TabItem>
</Tabs>

## Build the CLI from source

The source build requires Rust 1.91 or newer:

```bash
git clone https://github.com/eidos-space/graft.git
cd graft
cargo build -p graft-cli --bin graft --release
./target/release/graft --version
```

Add `target/release/graft` to `PATH` if you intend to use the source build
outside the repository.
