---
title: Resolve Row Conflicts
description: Merge two branches that edited the same SQLite rows and choose ours or theirs for each conflicting row.
---

When two branches change the same row, `graft merge` leaves a row conflict
instead of binary conflict markers. Resolve each row on its own.

## 1. Seed a database with three rows

```bash
graft init
sqlite3 data.sqlite "CREATE TABLE notes(id INTEGER PRIMARY KEY, body TEXT); INSERT INTO notes(body) VALUES('alpha'),('beta'),('gamma');"
graft add -A && graft commit -m init
```

## 2. Change rows on both branches

```bash
graft branch fix && graft switch fix
sqlite3 data.sqlite "UPDATE notes SET body='alpha-fix' WHERE id=1; UPDATE notes SET body='beta-fix' WHERE id=2;"
graft add -A && graft commit -m fix

graft switch main
sqlite3 data.sqlite "UPDATE notes SET body='alpha-main' WHERE id=1; UPDATE notes SET body='beta-main' WHERE id=2;"
graft add -A && graft commit -m main
```

## 3. Review the divergence before merging

```bash
graft diff main fix --rows
```

```text
Row Diff 71c68854b187..d833336e464c
modified: data.sqlite
  Table 'notes': ~2 updates
    ~ rowid 1:
      old: [Null, Text("alpha-main")]
      new: [Null, Text("alpha-fix")]
    ~ rowid 2:
      old: [Null, Text("beta-main")]
      new: [Null, Text("beta-fix")]
```

## 4. Merge

```bash
graft merge fix
```

```text
Merged 3dd17df3b1dc
Unmerged paths:
  data.sqlite
```

During the conflict the worktree keeps the ours candidate, so `sqlite3` still
shows the `main` values.

## 5. Resolve one row at a time

`--row <table> <identity>` selects one row conflict. Pair it with `--ours` or
`--theirs`; the path argument is still required.

```bash
graft resolve --theirs --row notes 1 data.sqlite
graft resolve --ours   --row notes 2 data.sqlite
graft merge --continue -m merge

sqlite3 -header -column data.sqlite "SELECT * FROM notes;"
```

```text
id  body
--  ---------
1   alpha-fix
2   beta-main
3   gamma
```

## Notes

- The worktree file is rewritten once the last row conflict is resolved, so run
  `sqlite3` after all `resolve` calls.
- Rows that only one side changed, such as row 3 here, merge automatically.
- Use `graft conflicts --json` to list conflict identities and both sides.
- To abandon the merge, run `graft merge --abort`.
- Hashes above are abbreviated and differ per machine.
