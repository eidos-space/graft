Git tracks a SQLite database as an opaque binary file. Graft understands
SQLite: it creates storage-efficient snapshots, shows schema and row-level
changes, and merges supported database changes. Related files can travel in the
same commit.

Graft uses a familiar Git-like workflow with its own repository and remote
formats.
