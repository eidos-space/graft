Git 会把 SQLite 数据库作为不透明的二进制文件跟踪。Graft 创建存储高效的快照，
展示表结构与行级变化，并合并受支持的数据库改动。
相关文件也可以包含在同一次提交中。

Graft 采用类似 Git 的工作流，并使用独立的仓库格式与远端机制。
