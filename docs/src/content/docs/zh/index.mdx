Graft 面向构建 SQLite 应用的开发者。它把 SQLite 数据库和应用文件记录为
同一个版本，让应用可以检查、恢复、建立分支、合并并同步完整状态。

```text
SQLite 负责事务，Graft 负责历史。
```
