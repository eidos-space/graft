最快的试用方式是 CLI。需要进程内集成时，应用可以使用常驻 Node.js/Electron SDK。

## 安装 CLI

```bash
curl -fsSL https://graft.eidos.space/install.sh \
  | GRAFT_VERSION=0.13.0 sh
graft --version
# graft-cli 0.13.0
```

<Aside type="note" title="最新 release">
  去掉 `GRAFT_VERSION=0.13.0` 会安装最新已发布版本。
</Aside>

也可以从
[GitHub releases](https://github.com/eidos-space/graft/releases)
下载预构建 archive。

## 从源码构建 CLI

在仓库根目录：

```bash
cargo build -p graft-cli --bin graft --release
```

生成位置：

```text
target/release/graft
```

加入 PATH：

```bash
mkdir -p ~/.local/bin
ln -sf "$(pwd)/target/release/graft" ~/.local/bin/graft
hash -r
graft --help
```

## 构建文档

```bash
cd docs
pnpm install
pnpm build
```

## 安装 Node.js 与 Electron SDK

```bash
pnpm add @eidos.space/graft
```

npm package 提供长生命周期的进程内 repository session 和预构建 Node-API 8 binary。
继续阅读 [Node.js 与 Electron SDK](/zh/docs/guides/node-electron-sdk/)。

下一步先跑 [CLI 快速开始](/zh/docs/quickstart/cli/)。应用需要常驻 repository session
时，再看 [Node.js 与 Electron SDK](/zh/docs/guides/node-electron-sdk/)。
