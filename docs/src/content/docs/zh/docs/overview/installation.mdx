只安装应用实际使用的接入面。

<Tabs>
  <TabItem label="CLI">

  ```bash
  curl -fsSL https://graft.eidos.space/install.sh | sh
  graft --version
  ```

  安装脚本会为当前平台下载最新发布的二进制文件。需要固定版本时：

  ```bash
  curl -fsSL https://graft.eidos.space/install.sh \
    | GRAFT_VERSION=0.15.3 sh
  ```

  也可以从 [GitHub Releases](https://github.com/eidos-space/graft/releases)
  下载预构建压缩包。

  安装后，可以使用下面的命令原地更新当前 CLI：

  ```bash
  graft upgrade
  ```

  </TabItem>
  <TabItem label="Node.js SDK">

  ```bash
  pnpm add @eidos.space/graft
  ```

  软件包支持 Node.js 20 及以上版本，并为当前平台选择预构建 Node-API 8 二进制文件。
  继续阅读 [SDK 快速开始](/zh/docs/sdk/quickstart/)。

  </TabItem>
  <TabItem label="远端服务">

  根据宿主环境选择软件包：

  ```bash
  pnpm add @eidos.space/graft-remote
  pnpm add @eidos.space/graft-remote-hono hono
  pnpm add @eidos.space/graft-remote-cloudflare
  ```

  选择协议引擎、路由适配器或 Cloudflare 存储适配器前，先阅读
  [远端服务](/zh/docs/remotes/)。

  </TabItem>
</Tabs>

## 从源码构建 CLI

源码构建需要 Rust 1.91 或更高版本：

```bash
git clone https://github.com/eidos-space/graft.git
cd graft
cargo build -p graft-cli --bin graft --release
./target/release/graft --version
```

如果要在仓库外使用源码构建，把 `target/release/graft` 加入 `PATH`。
