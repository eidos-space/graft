英文规范定义 Graft 的可观察契约。实现兼容适配器、审查行为变更或判断规则归属时，
应以英文规范为准。普通产品接入请使用任务指南。

| SQLite 存储快照与恢复语义 | [Graft Storage Snapshots 1.0](https://github.com/eidos-space/graft/blob/main/docs/specs/graft-storage-snapshots-1.0.md) |

先阅读[规范索引](https://github.com/eidos-space/graft/blob/main/docs/specs/README.zh.md)，
了解职责归属、conformance 标记和规范层次。

## 契约与实现

仓库标识、快照内容、差异与合并结果、适配器安全边界和远端发布顺序属于可观察
契约。缓存文件名、Rust 模块边界、临时路径和存储引擎 key encoding 属于实现细节，
除非规范另有说明。

行为发生变化时，应同时更新所属规范与可执行 conformance evidence。
