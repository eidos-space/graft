# Graft Docker 0.2.0

新服务器现在可以在浏览器中完成设置。启动容器、打开一次性初始化链接，
选择本地磁盘或 S3 兼容存储，Graft 会自动生成访问密钥并显示连接 Eidos Lite
所需的信息。初始化页面支持简体中文和英文。

- 在 `/setup` 中配置 S3 凭据，测试桶内对象的读、写、删除。
- 初始化状态和凭据保存在私有数据卷中，重启不会丢失；可以通过服务器管理命令取回遗失的访问密钥。
- 使用已有 HTTPS 代理或部署平台，也可以添加可选的 Caddy Compose 配置。Caddy 不是必需依赖。
- 已有外部密钥文件部署继续可用并跳过网页初始化。升级时保留原 Compose 文件和数据；新模板通过 `compose.secrets.yaml` 支持外部管理的密钥。

发布包含 Linux AMD64 和 ARM64 原生镜像，以及固定镜像摘要的 Compose 文件。
服务依赖仍为 Remote 0.2.6 和 SDK 0.3.39。

升级前停止服务器，备份数据卷及外部密钥。S3 安装还需备份对应桶内数据。
更换存储后端需要另建部署并通过客户端迁移，初始化流程不会迁移已有服务器。
