# Graft Docker 0.2.1

初始化页面现在会先验证私有链接，再显示存储字段。直接打开服务器根地址或
`/setup` 时，会先给出获取链接的命令和下一步说明，确认授权后再填写存储信息。

- 复制 `setup-link` 命令，在服务器的 Compose 目录中执行，再打开命令输出的
  完整网址，包括 `#token=…` 部分。
- 链接无效、来源地址不匹配、验证请求失败或设置已完成时，分别提供具体恢复
  操作。入口指引支持简体中文和英文。
- 切换语言或选择 S3 不会清除授权说明。存储检查失败后仍可更正；另一个标签页
  完成初始化后，旧标签页的表单会关闭。

此补丁保留已有服务器数据、访问密钥和存储配置。升级前请停止服务器，备份
数据卷及外部密钥；S3 安装还需备份对应桶内数据。从 0.1.1 延续外部访问密钥
文件的安装，请保留原 Compose 文件及密钥挂载，继续跳过网页初始化。
重启和升级不会重新开放初始化。更换存储后端仍需另建部署并通过客户端迁移。

发布包含 Linux AMD64 和 ARM64 镜像，以及固定镜像摘要的 Compose 文件。
服务依赖仍为 Remote 0.2.6 和 SDK 0.3.39。
